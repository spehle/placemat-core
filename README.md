# placemat-core

> ⚠️ **Status: Paused / Inactive (since March 2026)**
> This project is currently not actively developed and is paused for an indefinite period.
>
> Placemat was originally intended as a personal open-source project to explore concepts in inventory and logistics systems as a hobby.
>
> As I am now working professionally in the field of intralogistics, I have decided to discontinue active development of this project in order to avoid any potential conflicts of interest.

Placemat Core is the backend and infrastructure foundation of **Placemat**,
an open-source inventory and logistics system inspired by real-world intralogistics.

## Goals

* Clean domain model for locations, transport units and inventory
* REST API usable by web frontends and TUIs
* PostgreSQL persistence with Flyway migrations
* Designed for containerized and Kubernetes-based deployments

## Tech Stack

* Java 21
* Spring Boot
* PostgreSQL
* Flyway
* REST API
* ncurses-based TUI client (planned)
